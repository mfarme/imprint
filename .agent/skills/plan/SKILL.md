# Plan

1. Read the issue, charter, and nearest local specifications.
2. Identify the user outcome and requirement IDs affected.
3. Trace dependencies through interfaces, invariants, scenarios, decisions, and implementation.
4. Propose the smallest coherent specification change.
5. List contradictions and human decisions before implementation work.
6. Define verification evidence and a rollback or migration strategy when relevant.

## Completion

Return a plan with files to change, intent deltas, scenarios to add or update, implementation impact, exact checks, assumptions, and explicit approval points.
